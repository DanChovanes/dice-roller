# Crappy Psuedorandoms Ideas

## The Printer Spooler Entropy
Count the number of documents currently in the print queue, multiply by the number of times any printer has reported a paper jam since boot, divide by the total pages printed today. If no printer exists, use the time since the last hypothetical print job was attempted.

## The Clipboard Chaos
Sample the clipboard contents every millisecond for 100ms, count how many times the content changes, use that as your seed, but only if the clipboard contains an odd number of vowels.

## The Window Title Scrambler
Take all open window titles, concatenate them, count the number of times the letter 'e' appears, multiply by the total character length, divide by the number of minimized windows, then feed that into a function that checks if Caps Lock is on.

## The Network Packet Diviner
Count the number of dropped network packets since boot, multiply by the current ping to 8.8.8.8, divide by the number of Wi-Fi networks visible (or 1 if none), then add the current DHCP lease time remaining.

## The Font Renderer's Revenge
Request the system render the letter A in 100 different fonts, time how long each takes, average the render times, multiply by the number of missing fonts, divide by the current DPI scaling factor.

## The Mouse Acceleration Paradox
 - Measure the mouse's position every frame for one second, calculate the variance in acceleration, multiply by the number of times the user has clicked today, divide by the scroll wheel's current direction (up = 1, down = -1, use absolute value at the end).

## The Battery Degradation Gambler
Take the battery's design capacity vs current maximum capacity difference, multiply by the charge cycle count, divide by the time remaining on the estimated battery life, but only if the power cord is currently connected.

## The File System Quantum Observer
Count all files modified in the last minute, multiply by the average file size of your Downloads folder, divide by the number of symbolic links broken, then add the current swap file usage percentage.

## The Display Color Depth Conspiracy
Sample a 1x1 pixel area of the screen every second for 5 seconds, check how many times the color changes, multiply by the current refresh rate, divide by the bit depth of the primary display, then modulo by the number of virtual desktops.

## The Ultimate Entropy Smoothie
Combine all of the above, but only if the system uptime modulo 7 equals the current phase of the moon represented as a number between 0 and 5, otherwise just use the number of running Docker containers times the system load average divided by the CPU temperature in Celsius (with a minimum divisor of 1, obviously).
